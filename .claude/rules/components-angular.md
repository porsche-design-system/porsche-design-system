# Angular Wrapper (`packages/components-angular/`)

Angular wrapper module for PDS web components.

## Package Structure

```
packages/components-angular/
├── src/                           # Angular dev app for testing
├── projects/
│   └── angular-wrapper/           # Generated Angular wrapper module
│       └── src/lib/
│           ├── components/        # {component}.wrapper.ts files
│           ├── utils.ts           # BaseComponent + ControlValueAccessor
│           └── barrel.ts          # DECLARATIONS array export
├── scripts/                       # Build scripts
└── tests/                         # Test files
```

## Wrapper Component Pattern

All wrappers follow this structure (generated — do not hand-edit):

```ts
import { Component } from '@angular/core';
import { BaseComponent } from '../../utils';
import type { FieldsetLabelSize, FieldsetState, SelectedAriaRole } from '../types';

@Component({
  selector: 'p-fieldset,[p-fieldset]',
  template: '<ng-content />',
  inputs: ['aria', 'label', 'labelSize', 'message', 'required', 'state'],
  standalone: false,
})
export class PFieldset extends BaseComponent {
  aria?: SelectedAriaRole<'radiogroup'>;
  label?: string;
  labelSize?: FieldsetLabelSize;
  message?: string;
  required?: boolean;
  state?: FieldsetState;
}
```

Key patterns:
- Selector includes both element and attribute forms: `'p-component,[p-component]'`
- Template is always `'<ng-content />'` — delegates content to web component
- `inputs` array lists all component props
- `outputs` array lists all custom events (when applicable)
- `standalone: false` — all components are part of `PorscheDesignSystemModule`
- Extends `BaseComponent` for prop synchronization

## BaseComponent (`utils.ts`)

```ts
export class BaseComponent implements OnChanges {
  constructor(protected elementRef: ElementRef, protected cdr: ChangeDetectorRef) {
    cdr.detach();  // Performance: detach change detection
  }

  public ngOnChanges(changes: SimpleChanges): void {
    // Syncs all changed Angular inputs to DOM element properties
    for (const [key, { currentValue }] of Object.entries(changes)) {
      (this.elementRef.nativeElement as any)[key] = currentValue;
    }
  }
}
```

Key: `cdr.detach()` disables Angular change detection for performance — props are synced directly to the DOM element.

## ControlValueAccessor (Form Components)

Form components implement `ControlValueAccessor` for Angular forms integration:

```ts
@Component({
  selector: 'p-input-text,[p-input-text]',
  template: '<ng-content />',
  inputs: ['aria', 'disabled', 'label', 'message', 'name', 'required', 'state', 'value'],
  outputs: ['change', 'blur', 'input'],
  standalone: false,
  providers: [{
    provide: NG_VALUE_ACCESSOR,
    useExisting: forwardRef(() => PInputText),
    multi: true,
  }],
})
export class PInputText extends BaseComponent implements ControlValueAccessor {
  change = new EventEmitter<CustomEvent<InputTextChangeEvent>>();
  blur = new EventEmitter<CustomEvent<FocusEvent>>();
  input = new EventEmitter<CustomEvent<InputEvent>>();

  writeValue(value: any): void { /* sync to element */ }
  registerOnChange(fn: any): void { /* store callback */ }
  registerOnTouched(fn: any): void { /* store callback */ }
  setDisabledState(isDisabled: boolean): void { /* sync disabled */ }
}
```

## Module Setup

### NgModule

```ts
import { PorscheDesignSystemModule } from '@porsche-design-system/components-angular';

@NgModule({
  imports: [BrowserModule, PorscheDesignSystemModule.load()],
})
export class AppModule {}
```

### Standalone Bootstrap

```ts
import { importProvidersFrom } from '@angular/core';
import { PorscheDesignSystemModule } from '@porsche-design-system/components-angular';

bootstrapApplication(AppComponent, {
  providers: [importProvidersFrom(PorscheDesignSystemModule.load())],
});
```

## ToastManager

Injectable service for toast notifications:
- Calls `addMessage()` on the `p-toast` element via `customElements.whenDefined()`
- Injected as an Angular service

## ARIA Usage

Use the `[aria]` input binding, not direct `aria-*` attributes:

```html
<!-- Correct -->
<p-button [aria]="{ 'aria-label': 'Close' }">X</p-button>

<!-- Incorrect -->
<p-button aria-label="Close">X</p-button>
```

## Build Dependencies

Requires built first: `shared` → `tokens` → `assets` → `styles` → `utilities` → `component-meta` → `components` → `components-js`

## Testing

Tests use Vitest for wrapper logic and Karma/Jasmine for Angular integration:
- Ensure wrapped components maintain accessibility
- Verify ARIA attribute passthrough works correctly
- Test two-way binding if applicable
