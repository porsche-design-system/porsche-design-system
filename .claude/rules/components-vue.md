# Vue Wrapper (`packages/components-vue/`)

Vue 3 wrapper for PDS web components.

## Package Structure

```
packages/components-vue/
├── src/                           # Vite dev app for testing
├── projects/
│   └── vue-wrapper/               # Generated Vue wrapper components
│       └── src/lib/
│           ├── components/        # {Component}Wrapper.vue files (PascalCase)
│           └── utils.ts           # syncProperties, usePrefix, event helpers
├── scripts/                       # Build scripts
└── tests/                         # Test files
```

## Wrapper Component Pattern

All wrappers follow this structure (generated — do not hand-edit):

```vue
<script setup lang="ts">
  import { onMounted, onUpdated, ref } from 'vue';
  import { syncProperties, usePrefix } from '../../utils';
  import type { FieldsetLabelSize, FieldsetState, SelectedAriaRole } from '../types';

  type PFieldsetProps = {
    aria?: SelectedAriaRole<'radiogroup'>;
    label?: string;
    labelSize?: FieldsetLabelSize;
    message?: string;
    required?: boolean;
    state?: FieldsetState;
  };

  const webComponentTag = usePrefix('p-fieldset');
  const props = withDefaults(defineProps<PFieldsetProps>(), {
    label: '',
    labelSize: 'medium',
    message: '',
    required: false,
    state: 'none',
  });
  const pdsComponentRef = ref<PFieldsetProps & HTMLElement>();
  const syncProps = (): void => syncProperties(pdsComponentRef, props);

  onMounted(syncProps);
  onUpdated(syncProps);
</script>

<template>
  <component :is="webComponentTag" ref="pdsComponentRef"><slot /></component>
</template>
```

Key patterns:
- `<script setup lang="ts">` Composition API with TypeScript
- `usePrefix()` resolves tag from provider context
- `withDefaults(defineProps<Props>(), { ... })` for typed props with defaults
- `ref<Props & HTMLElement>()` for template ref to the web component element
- `syncProperties()` called on both `onMounted` and `onUpdated`
- Template uses `<component :is="...">` for dynamic tag rendering

## Form Component Wrapper (with events)

```vue
<script setup lang="ts">
  import { onMounted, onUpdated, ref } from 'vue';
  import { syncProperties, addEventListenerToElementRef, usePrefix } from '../../utils';

  const emit = defineEmits<{
    (e: 'update:value', value: string): void;
    (e: 'change', value: CustomEvent<InputTextChangeEvent>): void;
    (e: 'input', value: CustomEvent<InputEvent>): void;
    (e: 'blur', value: CustomEvent<FocusEvent>): void;
  }>();

  onMounted(() => {
    syncProps();
    addEventListenerToElementRef(pdsComponentRef, 'change', emit, (e) => {
      emit('update:value', (e as CustomEvent<InputTextChangeEvent>).detail.value);
    });
    addEventListenerToElementRef(pdsComponentRef, 'blur', emit);
    addEventListenerToElementRef(pdsComponentRef, 'input', emit);
  });
</script>
```

Key: `addEventListenerToElementRef()` bridges custom events from web components. The `update:value` emit enables v-model support.

## Utility Functions (`utils.ts`)

| Function | Purpose |
|----------|---------|
| `usePrefix(tagName)` | Resolve prefixed component tag from injection context |
| `syncProperties(ref, props)` | Set all prop values on the DOM element |
| `addEventListenerToElementRef(ref, event, emit, callback?)` | Bridge events to Vue emits |
| `prefixInjectionKey` | Symbol for provide/inject prefix |

## Provider Pattern

### Component-Based

```vue
<script setup lang="ts">
import { PorscheDesignSystemProvider, PButton } from '@porsche-design-system/components-vue';
</script>

<template>
  <PorscheDesignSystemProvider>
    <PButton>Click me</PButton>
  </PorscheDesignSystemProvider>
</template>
```

### Plugin-Based

```ts
import { createApp } from 'vue';
import { createPorscheDesignSystem } from '@porsche-design-system/components-vue';

const app = createApp(App);
app.use(createPorscheDesignSystem());
app.mount('#app');
```

The provider uses `provide(prefixInjectionKey, prefix)` and calls `load()` from `@porsche-design-system/components-js`.

## ARIA Usage

Use `:aria` prop binding, not direct `aria-*` attributes:

```vue
<!-- Correct -->
<PButton :aria="{ 'aria-label': 'Close' }">X</PButton>

<!-- Incorrect -->
<PButton aria-label="Close">X</PButton>
```

## v-model Support

Form components support v-model via `update:value` emit:

```vue
<PInputText v-model:value="textValue" />
```

Test v-model bindings when modifying form component wrappers.
