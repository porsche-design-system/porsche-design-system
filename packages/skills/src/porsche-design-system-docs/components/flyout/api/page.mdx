# Flyout 

### API Reference for `p-flyout`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `open` | `boolean` | `false` | If true, the flyout is open. **(required)** |
| `position` | `"start" \| "end"` | `"end"` | The position of the flyout |
| `disableBackdropClick` | `boolean` | `false` | If true, the flyout will not be closable via backdrop click. |
| `background` | `"canvas" \| "surface"` | `"canvas"` | Defines the background color |
| `backdrop` | `"blur" \| "shading"` | `"blur"` | Defines the backdrop, 'blur' (should be used when the underlying content is not relevant for users) and 'shading' (should be used when the user still needs a visual connection to the underlying content). |
| `footerBehavior` | `"sticky" \| "fixed"` | `"sticky"` | Determines the footer's position behavior. When set to "fixed," the flyout content stretches to fill the full height, keeping the footer permanently at the bottom. When set to "sticky," the footer flows beneath the content and only becomes fixed if the content overflows. |
| `aria` | `{ aria-label: string }` | - | Sets ARIA attributes. |

#### Events

| Event | Type | Description |
|-------|------|-------------|
| `dismiss` | `void` | Emitted when the component requests to be dismissed. |
| `motionVisibleEnd` | `TransitionEvent` | Emitted when the flyout is opened and the transition is finished. |
| `motionHiddenEnd` | `TransitionEvent` | Emitted when the flyout is closed and the transition is finished. |

#### Slots

| Slot | Description |
|------|-------------|
| `header` | Renders a sticky header section above the content area. |
| (default) | Default slot for the main content. |
| `footer` | Shows a sticky footer section, flowing under the content area when scrollable. |
| `sub-footer` | Renders additional content below the footer, such as legal information or FAQs. It appears when the flyout has enough space or when the user scrolls to the end. |

#### CSS Custom Properties

| Variable | Default | Description |
|----------|---------|-------------|
| `--p-flyout-width` | `auto` | Width of the flyout. |
| `--ref-p-flyout-pt` | - | Exposes the internally used padding-top of the Flyout as read only CSS variable. When slotting e.g. a media container, this variable can be used to stretch the element to the top of the Flyout. |
| `--ref-p-flyout-pb` | - | Exposes the internally used padding-bottom of the Flyout as read only CSS variable. When slotting e.g. a media container, this variable can be used to stretch the element to the bottom of the Flyout. |
| `--ref-p-flyout-px` | - | Exposes the internally used padding-inline of the Flyout as read only CSS variable. When slotting e.g. a media container, this variable can be used to stretch the element to the full horizontal size of the Flyout. |
