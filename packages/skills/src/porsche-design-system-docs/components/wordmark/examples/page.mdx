# Wordmark 

## Size

By default, the sizing is fluid, which can be changed to `inherit` a specified value.

### Interactive Story: `wordmarkStorySizeInherit`

```html
<p-wordmark class="h-[20px]" size="inherit"></p-wordmark>
```

## Custom clickable/focusable area

Sometimes it may be useful to enlarge the clickable/focusable area of the `p-wordmark`. Therefore, custom padding can be
set on the host element.

### Interactive Story: `wordmarkStoryCustomPadding`

```html
<p-wordmark class="p-static-md" href="https://porsche.com" aria="{'aria-label': 'Porsche Homepage'}"></p-wordmark>
```
