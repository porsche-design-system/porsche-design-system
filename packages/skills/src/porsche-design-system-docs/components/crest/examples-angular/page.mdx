# Crest 

## Link

The Porsche Crest will be rendered as `<a>`-tag as soon as an `href` is provided.

### Interactive Story: `crestStoryLink`

```typescript
import { ChangeDetectionStrategy, Component } from '@angular/core';
import { PorscheDesignSystemModule } from '@porsche-design-system/components-angular';

@Component({
  selector: 'porsche-design-system-app',
  template: `
      <p-crest href="https://porsche.com" [aria]="{'aria-label': 'Porsche Homepage'}"></p-crest>
  `,
  changeDetection: ChangeDetectionStrategy.OnPush,
  standalone: true,
  imports: [PorscheDesignSystemModule], // <-- PDS module is imported here
})
export class ExampleComponent {}
```

## Custom clickable/focusable area

Sometimes it may be useful to enlarge the clickable/focusable area of the Porsche Crest. Therefore, custom padding can
be set on the host element.

### Interactive Story: `crestStoryCustomPadding`

```typescript
import { ChangeDetectionStrategy, Component } from '@angular/core';
import { PorscheDesignSystemModule } from '@porsche-design-system/components-angular';

@Component({
  selector: 'porsche-design-system-app',
  template: `
      <p-crest href="https://porsche.com" class="p-static-md" [aria]="{'aria-label': 'Porsche Homepage'}"></p-crest>
  `,
  changeDetection: ChangeDetectionStrategy.OnPush,
  standalone: true,
  imports: [PorscheDesignSystemModule], // <-- PDS module is imported here
})
export class ExampleComponent {}
```
