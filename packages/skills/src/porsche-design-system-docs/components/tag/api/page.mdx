# Tag

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `variant` | `"primary" \| "secondary" \| "info" \| "info-frosted" \| "warning" \| "warning-frosted" \| "success" \| "success-frosted" \| "error" \| "error-frosted"` | `"secondary"` | Background color variations. |
| `icon` | `TagIcon` | `"none"` | The icon shown. 291 allowed values. |
| `iconSource` | `string` | - | A URL path to a custom icon. |
| `compact` | `boolean` | `false` | Displays the tag in compact mode. |
