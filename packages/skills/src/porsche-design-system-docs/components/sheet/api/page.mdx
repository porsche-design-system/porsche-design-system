# Sheet 

### API Reference for `p-sheet`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `open` | `boolean` | `false` | If true, the sheet is open. **(required)** |
| `dismissButton` | `boolean` | `true` | If false, the sheet will not have a dismiss button. |
| `disableBackdropClick` | `boolean` | `false` | If true, the sheet will not be closable via backdrop click. |
| `background` | `"canvas" \| "surface"` | `"canvas"` | Defines the background color |
| `aria` | `{ aria-label: string, role: string }` | - | Sets ARIA attributes. |

#### Events

| Event | Type | Description |
|-------|------|-------------|
| `dismiss` | `void` | Emitted when the component requests to be dismissed. |
| `motionVisibleEnd` | `TransitionEvent` | Emitted when the sheet is opened and the transition is finished. |
| `motionHiddenEnd` | `TransitionEvent` | Emitted when the sheet is closed and the transition is finished. |

#### Slots

| Slot | Description |
|------|-------------|
| `header` | Renders a header section above the content area. |
| (default) | Default slot for the main content. |

#### CSS Custom Properties

| Variable | Default | Description |
|----------|---------|-------------|
| `--ref-p-sheet-pt` | - | Exposes the internally used padding-top of the Sheet as read only CSS variable. When slotting e.g. a media container, this variable can be used to stretch the element to the top of the Sheet. |
| `--ref-p-sheet-pb` | - | Exposes the internally used padding-bottom of the Sheet as read only CSS variable. When slotting e.g. a media container, this variable can be used to stretch the element to the bottom of the Sheet. |
| `--ref-p-sheet-px` | - | Exposes the internally used padding-inline of the Sheet as read only CSS variable. When slotting e.g. a media container, this variable can be used to stretch the element to the full horizontal size of the Sheet. |
