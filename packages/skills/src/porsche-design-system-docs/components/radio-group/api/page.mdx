# Radio Group 

## Radio Group

### API Reference for `p-radio-group`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `""` | Text content for a user-facing label. |
| `description` | `string` | `""` | Supplementary text providing more context or explanation for the radio group. |
| `compact` | `boolean` | `false` | Displays the radio group in compact mode. |
| `direction` | `"row" \| "column"` | `"column"` | Defines the direction of the main and cross-axis. The default is `column`, which stacks the options vertically. You always need to provide a base value when using breakpoints. *(breakpoint customizable)* |
| `name` | `string` | - | The name of the group of radio buttons, used when submitting the form data. **(required)** |
| `value` | `string` | `""` | The default value for the radio-group. |
| `form` | `string` | - | Specifies the id of the <form> element that the radio group belongs to (useful if the radio group is not a direct descendant of the form). |
| `disabled` | `boolean` | `false` | Disables the radio group. The value will not be submitted with the form. |
| `required` | `boolean` | `false` | A boolean value that specifies a selection must be made from the group before the form can be submitted. |
| `loading` | `boolean` | `false` | @experimental Shows a loading indicator. |
| `state` | `"none" \| "error" \| "success"` | `"none"` | Indicates the validation or overall status of the radio group component. |
| `message` | `string` | `""` | Dynamic feedback text for validation or status. |
| `hideLabel` | `boolean` | `false` | Shows or hides the label. For better accessibility, it is recommended to show the label. *(breakpoint customizable)* |

#### Events

| Event | Type | Description |
|-------|------|-------------|
| `blur` | `void` | Emitted when the radio-group has lost focus. |
| `change` | `Event` | Emitted when the selected option is changed. |

#### Slots

| Slot | Description |
|------|-------------|
| `label` | Shows a label. Only [phrasing content](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/Content_categories#Phrasing_content) is allowed. |
| `label-after` | Places additional content after the label text (for content that should not be part of the label, e.g. external links or `p-popover`). |
| `description` | Shows a description. Only [phrasing content](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/Content_categories#Phrasing_content) is allowed. |
| (default) | Default slot for the p-radio-group-option tags. |
| `message` | Shows a state message. Only [phrasing content](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/Content_categories#Phrasing_content) is allowed. |

## Radio Group Option

### API Reference for `p-radio-group-option`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `value` | `string` | - | The value for the input. |
| `label` | `string` | - | Text content for a user-facing label. |
| `disabled` | `boolean` | `false` | Disables the radio group option. The value will not be submitted with the form. |
| `loading` | `boolean` | `false` | @experimental Shows a loading indicator. |

#### Slots

| Slot | Description |
|------|-------------|
| `label` | Shows a label. Only [phrasing content](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/Content_categories#Phrasing_content) is allowed. |
| `label-after` | Places additional content after the label text (for content that should not be part of the label, e.g. external links or `p-popover`). |
