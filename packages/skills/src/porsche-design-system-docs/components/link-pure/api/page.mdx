# Link Pure 

### API Reference for `p-link-pure`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `alignLabel` | `"start" \| "end"` | `"end"` | Aligns the label. *(breakpoint customizable)* |
| `stretch` | `boolean` | `false` | Stretches the area between icon and label to max available space. *(breakpoint customizable)* |
| `size` | `"2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl" \| "3xl" \| "4xl" \| "5xl" \| "inherit" \| "xx-small" \| "x-small" \| "small" \| "medium" \| "large" \| "x-large"` | `"sm"` | Size of the link. *(breakpoint customizable)* |
| `color` | `"primary" \| "contrast-higher" \| "contrast-high" \| "contrast-medium" \| "inherit"` | `"primary"` | The color. |
| `icon` | `LinkPureIcon` | `"arrow-right"` | The icon shown. By choosing 'none', no icon is displayed 291 allowed values. |
| `iconSource` | `string` | - | A URL path to a custom icon. |
| `underline` | `boolean` | `false` | Shows an underline under the label. |
| `href` | `string` | - | When `href` is provided, the component renders as an `<a>` element. |
| `active` | `boolean` | `false` | Displays the link in its active state. |
| `hideLabel` | `boolean` | `false` | Shows or hides the label. For better accessibility, it is recommended to show the label. *(breakpoint customizable)* |
| `target` | `"_self" \| "_blank" \| "_parent" \| "_top" \| "string"` | `"_self"` | Specifies where to open the linked document. |
| `download` | `string` | - | Sets the native `download` attribute when the target URL points to a downloadable file. |
| `rel` | `string` | - | Sets the `rel` attribute on the link. |
| `aria` | `{ aria-label: string, aria-description: string, aria-current: string, aria-haspopup: string }` | - | Sets ARIA attributes. |

#### Slots

| Slot | Description |
|------|-------------|
| (default) | Default slot to render the link label. |
