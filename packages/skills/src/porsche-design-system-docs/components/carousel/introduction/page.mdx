# Carousel 

The `p-carousel` component allows related or similar content to be consumed on a step by step basis with a better
overview than just showing them in a grid or as a list. The reason for this is, that only a certain amount of slides is
visible at the same time.

Therefore, the `p-carousel`'s content has to be divided into multiple parts or slides. The amount of slides visible can
be specified on a per-breakpoint basis.

> ⚠️ **Layout hint**
>
> When using the `width` prop to align with the **[Porsche Grid](/tailwindcss/grid/examples/)**, the component must span the full viewport width.
> 
> When using the `--p-carousel-px` CSS variable, the component can be placed within any container, allowing you
> to customize the horizontal padding that reveals parts of the next/previous slide.
> 
> When using the `--p-carousel-ps` and `--p-carousel-pe` CSS variables, the component can be placed
> within any container, allowing you to customize the horizontal padding asymmetric that reveals parts of the
> next/previous slide.

> ⚠️ **Dynamic changes**
>
> This component has limited support for dynamic property changes due to the way it is implemented.
> 
> 
> 
> If you need to use a specific property dynamically, please open a
> [feature request](/help/feature-request/).

> **Interactive Configurator**: Try the `p-carousel` configurator in the live documentation to customize all properties interactively.
