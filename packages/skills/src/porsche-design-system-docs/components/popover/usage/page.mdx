# Popover 

## Usage

The following section provides guidance for designers and developers on how to use this component in different
situations.

### Do:

- Use it to display additional information that is not necessary for task completion or to provide further explanation
  about a workflow.
- Position popovers in a way that they do not block related content.
- Choose a preferred direction in which the popover should open, or it will automatically open in the direction with the
  most available space.
- Use it consistently throughout your site.

### Don't:

- Don't use for content that can be displayed directly.
