# Popover 

### API Reference for `p-popover`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `direction` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred direction in which the popover should open when there is enough space in the viewport. Otherwise, it opens in the direction with the most available space. |
| `description` | `string` | - | Descriptive text shown when the popover is open. |
| `aria` | `{ aria-label: string }` | - | Sets ARIA attributes. |

#### Slots

| Slot | Description |
|------|-------------|
| (default) | Default slot for the popover content. |
| `button` | Slot for custom button. |
