# Text 

`p-text` is used to specify paragraph styling in documents.

> ✅ **Recommendation**
>
> Although the component is very sophisticated, it's recommended (if possible) to use the corresponding utility classes
> of the "@porsche-design-system/components-\{js | angular | react | vue}/tailwindcss" sub-package or any of the other
> styling solutions for best performance since way less DOM nodes are required to render. Further information can be
> found [here](/tailwindcss/typography/examples/).

> **Interactive Configurator**: Try the `p-text` configurator in the live documentation to customize all properties interactively.
