# Input Date 

### API Reference for `p-input-date`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `""` | Text content for a user-facing label. |
| `step` | `number` | `1` | Defines the granularity of the date input. This value is given in days. The default is 1 (one day). |
| `description` | `string` | `""` | Supplementary text providing more context or explanation for the input. |
| `compact` | `boolean` | `false` | Displays the input field in compact mode. |
| `name` | `string` | - | The name of the input field, used when submitting the form data. **(required)** |
| `value` | `"string" \| "null"` | `""` | The default date value for the input, in YYYY-MM-DD format (e.g., value='2025-07-02'). |
| `autoComplete` | `string` | - | Provides a hint to the browser about what type of data the field expects, which can assist with autofill features (e.g., autocomplete='bday' for a birthday). |
| `readOnly` | `boolean` | `false` | A boolean value that, if present, makes the input field uneditable by the user, but its value will still be submitted with the form. |
| `form` | `string` | - | Specifies the id of the <form> element that the input belongs to (useful if the input is not a direct descendant of the form). |
| `max` | `string` | - | Specifies the latest date that can be selected. The value must be a date string in YYYY-MM-DD format (e.g., max='2024-12-31'). |
| `min` | `string` | - | Specifies the earliest date that can be selected. The value must be a date string in YYYY-MM-DD format (e.g., min='2023-01-01'). |
| `disabled` | `boolean` | `false` | Disables the input field. The value will not be submitted with the form. |
| `required` | `boolean` | `false` | A boolean value that, if present, indicates that the input field must be filled out before the form can be submitted. |
| `loading` | `boolean` | `false` | @experimental Shows a loading indicator. |
| `state` | `"none" \| "error" \| "success"` | `"none"` | Indicates the validation or overall status of the input component. |
| `message` | `string` | `""` | Dynamic feedback text for validation or status. |
| `hideLabel` | `boolean` | `false` | Shows or hides the label. For better accessibility, it is recommended to show the label. *(breakpoint customizable)* |

#### Events

| Event | Type | Description |
|-------|------|-------------|
| `change` | `Event` | Emitted when the date input loses focus after its value was changed. |
| `blur` | `Event` | Emitted when the date input has lost focus. |
| `input` | `InputEvent` | Emitted when the value has been changed as a direct result of a user action. |

#### Slots

| Slot | Description |
|------|-------------|
| `label` | Shows a label. Only [phrasing content](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/Content_categories#Phrasing_content) is allowed. |
| `label-after` | Places additional content after the label text (for content that should not be part of the label, e.g. external links or `p-popover`). |
| `description` | Shows a description. Only [phrasing content](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/Content_categories#Phrasing_content) is allowed. |
| `message` | Shows a state message. Only [phrasing content](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/Content_categories#Phrasing_content) is allowed. |
| `start` | Shows content at the start of the input (e.g. unit prefix). |
| `end` | Shows content at the end of the input (e.g. toggle button, unit suffix). |

#### CSS Custom Properties

| Variable | Default | Description |
|----------|---------|-------------|
| `--ref-p-input-slotted-padding` | - | When slotting a `p-button-pure` or `p-link-pure` this variable needs to be set as `padding` in oder to adjust the alignment correctly. |
| `--ref-p-input-slotted-margin` | - | When slotting a `p-button-pure` or `p-link-pure` this variable needs to be set as `margin` in oder to adjust the spacings correctly. |
