# Tag Dismissible 

### API Reference for `p-tag-dismissible`

#### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | - | Text content for a user-facing label. |
| `aria` | `{ aria-label: string }` | - | Sets ARIA attributes. |
| `compact` | `boolean` | `false` | Displays the dismissible tag in compact mode. |

#### Slots

| Slot | Description |
|------|-------------|
| (default) | Default slot for the tag content. |
