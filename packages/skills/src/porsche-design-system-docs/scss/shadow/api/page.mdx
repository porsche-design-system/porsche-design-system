# Shadow

## SCSS Variables

| SCSS Variable                            | Description                  | Value                                   |
| ---------------------------------------- | ---------------------------- | --------------------------------------- |
| $shadow-lg | Holds a **large** `shadow`.  | 0px 3px 8px rgba(0,0,0,.16) |
| $shadow-md | Holds a **medium** `shadow`. | 0px 4px 16px rgba(0,0,0,.16) |
| $shadow-sm | Holds a **small** `shadow`.  | 0px 8px 40px rgba(0,0,0,.16) |
