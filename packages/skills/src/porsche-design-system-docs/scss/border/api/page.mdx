# Border

## SCSS Variables

### Radius

| SCSS Variable                              | Description                                | Value                                     |
| ------------------------------------------ | ------------------------------------------ | ----------------------------------------- |
| $radius-xs   | Holds a **x-small** `border-radius`.       | 2px   |
| $radius-sm   | Holds a **small** `border-radius`.         | 4px   |
| $radius-md   | Holds a **medium** `border-radius`.        | 6px   |
| $radius-lg   | Holds a **large** `border-radius`.         | 8px   |
| $radius-xl   | Holds a **x-large** `border-radius`.       | 12px   |
| $radius-2xl  | Holds a **2x-large** `border-radius`.      | 16px  |
| $radius-3xl  | Holds a **3x-large** `border-radius`.      | 24px  |
| $radius-4xl  | Holds a **4x-large** `border-radius`.      | 32px  |
| $radius-full | Holds a **fully** rounded `border-radius`. | calc(infinity * 1px) |
