# Breakpoint

## Tokens

| Token           | Description                                                                 | Value           |
| --------------- | --------------------------------------------------------------------------- | --------------- |
| breakpointXs  | Holds the `xs` breakpoint value, usable with `px` (**480px**).   | 480  |
| breakpointSm  | Holds the `sm` breakpoint value, usable with `px` (**760px**).   | 760  |
| breakpointMd  | Holds the `md` breakpoint value, usable with `px` (**1000px**).   | 1000  |
| breakpointLg  | Holds the `lg` breakpoint value, usable with `px` (**1300px**).   | 1300  |
| breakpointXl  | Holds the `xl` breakpoint value, usable with `px` (**1760px**).   | 1760  |
| breakpoint2Xl | Holds the `2xl` breakpoint value, usable with `px` (**1920px**). | 1920 |
