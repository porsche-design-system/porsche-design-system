# Border

## Tokens

### Radius

| Token        | Description                       | Value        |
| ------------ | --------------------------------- | ------------ |
| radiusXs   | Holds a **xs** `border-radius`.   | 2px   |
| radiusSm   | Holds a **sm** `border-radius`.   | 4px   |
| radiusMd   | Holds a **md** `border-radius`.   | 6px   |
| radiusLg   | Holds a **lg** `border-radius`.   | 8px   |
| radiusXl   | Holds a **xl** `border-radius`.   | 12px   |
| radius2Xl  | Holds a **2xl** `border-radius`.  | 16px  |
| radius3Xl  | Holds a **3xl** `border-radius`.  | 24px  |
| radius4Xl  | Holds a **4xl** `border-radius`.  | 32px  |
| radiusFull | Holds a **full** `border-radius`. | calc(infinity * 1px) |
