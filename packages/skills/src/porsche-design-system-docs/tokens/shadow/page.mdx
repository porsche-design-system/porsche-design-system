# Shadow

## Tokens

| Token      | Description                      | Value      |
| ---------- | -------------------------------- | ---------- |
| shadowLg | Holds a **high** `box-shadow`.   | 0px 8px 40px rgba(0,0,0,.16) |
| shadowMd | Holds a **medium** `box-shadow`. | 0px 4px 16px rgba(0,0,0,.16) |
| shadowSm | Holds a **low** `box-shadow`.    | 0px 3px 8px rgba(0,0,0,.16) |
