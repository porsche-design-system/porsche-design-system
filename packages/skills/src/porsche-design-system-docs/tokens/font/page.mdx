# Font

## Tokens

### Font Family

| Token                                         | Description                                                       | Value                                          |
| --------------------------------------------- | ----------------------------------------------------------------- | ---------------------------------------------- |
| fontPorscheNext | Holds the **Porsche Next** font family along with fallback fonts. | 'Porsche Next','Arial Narrow',Arial,'Heiti SC',SimHei,sans-serif |
