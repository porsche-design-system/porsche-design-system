# Color

The Porsche Design System provides multiple JS Variables for color styles to be used in Vanilla Extract.

The colors use the
[light-dark()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark) CSS color
function. To change the theme, use the utility classes `.scheme-light`, `.scheme-dark` or `.scheme-light-dark`. Learn
more in the [Color Scheme](/vanilla-extract/introduction#color-scheme) section.

Styles import:
`import { colorPrimary, colorFrosted, … } from '@porsche-design-system/components-{js|angular|react|vue}/vanilla-extract';`
