# Border

## JS

### Radius

| JS                                               | Description                                | Value                                           |
| ------------------------------------------------ | ------------------------------------------ | ----------------------------------------------- |
| radiusXs   | Holds a **x-small** `border-radius`.       | 2px   |
| radiusSm   | Holds a **small** `border-radius`.         | 4px   |
| radiusMd   | Holds a **medium** `border-radius`.        | 6px   |
| radiusLg   | Holds a **large** `border-radius`.         | 8px   |
| radiusXl   | Holds a **x-large** `border-radius`.       | 12px   |
| radius2Xl  | Holds a **2x-large** `border-radius`.      | 16px  |
| radius3Xl  | Holds a **3x-large** `border-radius`.      | 24px  |
| radius4Xl  | Holds a **4x-large** `border-radius`.      | 32px  |
| radiusFull | Holds a **fully** rounded `border-radius`. | calc(infinity * 1px) |
