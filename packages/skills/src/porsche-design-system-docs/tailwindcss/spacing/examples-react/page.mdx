# Spacing

The Porsche Design System Tailwind theme customizes the Tailwind variable `--spacing-*`, which affect multiple Tailwind
classes including `.m-fluid-*`, `.m-static-*`, `.p-fluid-*`, `.p-static-*`, `.w-fluid-*`, `.w-static-*`, `.h-fluid-*`,
`.h-static-*` and others.

## Fluid

Spacing scales dynamically based on the viewport width, within defined minimum and maximum limits. Mainly intended for
**vertical** spacing between elements.

### Interactive Story: `spacingFluidStory`

```tsx
import React from 'react';

export const Example = () => {
  return (
    <>
      <ul className="grid gap-fluid-md prose-text-sm">
        <li className="flex items-center gap-static-md">
          <div className="w-fluid-xs h-fluid-xs bg-[blue]/50"></div>
          .w-fluid-xs .h-fluid-xs
        </li>
        <li className="flex items-center gap-static-md">
          <div className="w-fluid-sm h-fluid-sm bg-[blue]/50"></div>
          .w-fluid-sm .h-fluid-sm
        </li>
        <li className="flex items-center gap-static-md">
          <div className="w-fluid-md h-fluid-md bg-[blue]/50"></div>
          .w-fluid-md .h-fluid-md
        </li>
        <li className="flex items-center gap-static-md">
          <div className="w-fluid-lg h-fluid-lg bg-[blue]/50"></div>
          .w-fluid-lg .h-fluid-lg
        </li>
        <li className="flex items-center gap-static-md">
          <div className="w-fluid-xl h-fluid-xl bg-[blue]/50"></div>
          .w-fluid-xl .h-fluid-xl
        </li>
        <li className="flex items-center gap-static-md">
          <div className="w-fluid-2xl h-fluid-2xl bg-[blue]/50"></div>
          .w-fluid-2xl .h-fluid-2xl
        </li>
      </ul>
    </>
  )
}
```

## Static
