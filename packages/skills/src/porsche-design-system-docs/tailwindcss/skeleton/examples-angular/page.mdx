# Skeleton

The Porsche Design System Tailwind theme includes the custom `@utility` CSS class `.skeleton` , which provides a
skeleton loading style.

### Interactive Story: `skeletonStory`

```typescript
import { ChangeDetectionStrategy, Component } from '@angular/core';
import { PorscheDesignSystemModule } from '@porsche-design-system/components-angular';

@Component({
  selector: 'porsche-design-system-app',
  template: `
      <div class="grid gap-fluid-sm prose-text-sm">
        <span class="skeleton p-fluid-sm">
          .skeleton
        </span>
        <span class="skeleton w-4/5 h-fluid-sm rounded-sm"></span>
        <span class="skeleton w-4/5 h-fluid-sm rounded-sm"></span>
        <span class="skeleton w-3/5 h-fluid-sm rounded-sm"></span>
      </div>
  `,
  changeDetection: ChangeDetectionStrategy.OnPush,
  standalone: true,
  imports: [PorscheDesignSystemModule], // <-- PDS module is imported here
})
export class ExampleComponent {}
```
