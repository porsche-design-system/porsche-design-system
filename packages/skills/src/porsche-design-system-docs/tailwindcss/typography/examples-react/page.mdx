# Typography

The Porsche Design System Tailwind theme includes the custom `@utility` CSS classes `.prose-display-*`,
`.prose-heading-*` and `.prose-text-*` to style headings and paragraphs consistently.

Additionally, it customizes Tailwind variables such as `--font-*`, `--leading-*` and `--text-*`, which affect multiple
Tailwind classes including `.font-*`, `.leading-*`, `.text-*` and others.
