# Shadow

The Porsche Design System Tailwind theme customizes the Tailwind variable `--shadow-*`, which affect multiple Tailwind
classes including `.shadow-*` and others.

### Interactive Story: `shadowStory`

```html
<div class="grid gap-fluid-md prose-text-sm">
  <div class="shadow-sm rounded-lg p-fluid-sm">
    .shadow-sm
  </div>
  <div class="shadow-md rounded-lg p-fluid-sm">
    .shadow-md
  </div>
  <div class="shadow-lg rounded-lg p-fluid-sm">
    .shadow-lg
  </div>
</div>
```
