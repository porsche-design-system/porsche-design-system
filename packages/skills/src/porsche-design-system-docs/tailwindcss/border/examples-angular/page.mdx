# Border

The Porsche Design System Tailwind theme customizes the Tailwind variables `--radius-*` and `--border-*`, which affect
multiple Tailwind classes including `.rounded-*`, `.border-*` and others.

## Border Radius

### Interactive Story: `borderRadiusStory`

```typescript
import { ChangeDetectionStrategy, Component } from '@angular/core';
import { PorscheDesignSystemModule } from '@porsche-design-system/components-angular';

@Component({
  selector: 'porsche-design-system-app',
  template: `
      <div class="grid gap-fluid-md prose-text-sm">
        <div class="rounded-xs border p-fluid-md">
          .rounded-xs
        </div>
        <div class="rounded-sm border p-fluid-md">
          .rounded-sm
        </div>
        <div class="rounded-md border p-fluid-md">
          .rounded-md
        </div>
        <div class="rounded-lg border p-fluid-md">
          .rounded-lg
        </div>
        <div class="rounded-xl border p-fluid-md">
          .rounded-xl
        </div>
        <div class="rounded-2xl border p-fluid-md">
          .rounded-2xl
        </div>
        <div class="rounded-3xl border p-fluid-md">
          .rounded-3xl
        </div>
        <div class="rounded-4xl border p-fluid-md">
          .rounded-4xl
        </div>
        <div class="rounded-full border p-fluid-md">
          .rounded-full
        </div>
      </div>
  `,
  changeDetection: ChangeDetectionStrategy.OnPush,
  standalone: true,
  imports: [PorscheDesignSystemModule], // <-- PDS module is imported here
})
export class ExampleComponent {}
```
