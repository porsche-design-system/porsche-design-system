# Motion

The Porsche Design System Tailwind theme customizes the Tailwind variables `--transition-duration-*` and `--ease-*`,
which affect multiple Tailwind classes including `.duration-*`, `.ease-*` and others.

## Duration

### Interactive Story: `motionStoryDuration`

```typescript
import { ChangeDetectionStrategy, Component } from '@angular/core';
import { PorscheDesignSystemModule } from '@porsche-design-system/components-angular';

@Component({
  selector: 'porsche-design-system-app',
  template: `
      <div class="grid gap-fluid-md prose-text-sm">
        <div class="duration-sm transition-transform transform hover:scale-120 rounded-lg bg-surface p-fluid-sm">
          .duration-sm
        </div>
        <div class="duration-md transition-transform transform hover:scale-120 rounded-lg bg-surface p-fluid-sm">
          .duration-md
        </div>
        <div class="duration-lg transition-transform transform hover:scale-120 rounded-lg bg-surface p-fluid-sm">
          .duration-lg
        </div>
        <div class="duration-xl transition-transform transform hover:scale-120 rounded-lg bg-surface p-fluid-sm">
          .duration-xl
        </div>
      </div>
  `,
  changeDetection: ChangeDetectionStrategy.OnPush,
  standalone: true,
  imports: [PorscheDesignSystemModule], // <-- PDS module is imported here
})
export class ExampleComponent {}
```
