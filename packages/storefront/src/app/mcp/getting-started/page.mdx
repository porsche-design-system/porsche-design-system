# Getting Started

The MCP server is distributed as an npm package. Add it to your MCP client configuration and your AI assistant will have
access to PDS documentation immediately.

## Cursor / VS Code

Add to your `.mcp.json` or project-level MCP configuration:

```json
{
  "mcpServers": {
    "pds-docs": {
      "command": "npx",
      "args": ["@porsche-design-system/mcp-server"]
    }
  }
}
```

## GitHub Copilot CLI

Add to your `~/.copilot/mcp-config.json`:

```json
{
  "mcpServers": {
    "pds-docs": {
      "type": "local",
      "command": "npx",
      "args": ["@porsche-design-system/mcp-server"],
      "env": {},
      "tools": ["*"]
    }
  }
}
```

Or use the interactive command within Copilot CLI:

1. Enter `/mcp add`
2. Set **Server Name** to `pds-docs`
3. Set **Server Type** to `STDIO`
4. Set **Command** to `npx @porsche-design-system/mcp-server`
5. Press `Ctrl+S` to save
