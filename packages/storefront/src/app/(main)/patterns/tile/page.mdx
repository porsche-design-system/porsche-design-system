A tile groups the content of a single item – a model, a category, a product or a feature – in an area that is often
clickable as a whole. Tiles vary too much in layout, media and interaction to be covered by a single component, so these
patterns show their common use cases, built with HTML, Tailwind CSS and the components of the Porsche Design System.
Start from the pattern closest to your use case and adapt it – the comments in its code explain why it is built the way
it is.
