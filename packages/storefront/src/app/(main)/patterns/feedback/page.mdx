# Feedback

<TableOfContents headings={['Inline', 'Dialog']} />

The feedback pattern lets users rate their satisfaction with a page on a five-point scale and, optionally, add a
comment. It gathers quick quantitative and qualitative input with minimal effort, revealing the comment field and submit
action only after a rating is chosen. Use it whenever you want to learn how users perceive a page or a specific task.
