# Forms

<TableOfContents headings={['Dealer results', 'Dealer links']} />

Coded examples for the form guidelines. A search field can offer matches without becoming a select. Choosing a match
writes that text into the field, and focus stays in the field while the arrow keys move through the list. When a match
is a page of its own, the same field offers links instead, and choosing one opens that page.
