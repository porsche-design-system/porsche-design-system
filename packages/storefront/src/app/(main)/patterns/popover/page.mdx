# Popover

<TableOfContents headings={['Local market switch', 'Priority navigation', 'Feature tour']} />

The popover displays contextual information or actions in a floating layer anchored to a trigger element. It helps
surface secondary content on demand without navigating away from the current context, keeping the primary interface
clean while remaining accessible.
