## Introduction

The Porsche Design System Knowledge Skill gives AI coding tools version-exact guidance for the PDS packages installed in
a project. It covers components, styles, tokens, accessibility and framework-specific usage, helping assistants answer
questions, generate UI and review or fix PDS code.

## How It Works

The Knowledge Skill ships inside the corresponding Porsche Design System npm package and is released together with it.
Since AI integrations discover skills in dedicated directories rather than `node_modules`, a directory symlink exposes
the bundled skill:

```text
.agents/skills/pds-knowledge-{js|angular|react|vue}
  -> node_modules/@porsche-design-system/components-{js|angular|react|vue}/skills/pds-knowledge-{js|angular|react|vue}
```

This **skill-in-package** approach provides two benefits:

- Updating the PDS dependency automatically updates the skill; there is no separately versioned skill to maintain.
- Keeping the skill in the package itself and linking it from the project where the package is installed avoids version
  mismatches.

## Installation

### 1. Install a Porsche Design System package

Install the package for your framework by following the Getting Started guide for
[Vanilla JavaScript](/developing/vanilla-js/getting-started), [Angular](/developing/angular/getting-started),
[React](/developing/react/getting-started) or [Vue](/developing/vue/getting-started).

### 2. Link the skill

Each supported Porsche Design System npm package includes the `pds-skill` binary to create the project-local symlink.
You can use the binary or create the symlink yourself.

#### Use the bundled binary

Run the binary from the project or workspace where the Porsche Design System package is installed:

```bash
npx pds-skill --package @porsche-design-system/components-{js|angular|react|vue} --location {.agents|.claude|.github}/skills
```

- For `--package`, use the Porsche Design System npm package installed in your project.
- `--location` sets the integration's parent skills directory. The binary creates the framework-specific skill folder
  inside it.

For example, link the React skill:

```bash
# Agent Skills standard and Codex
npx pds-skill --package @porsche-design-system/components-react --location .agents/skills

# Claude Code
npx pds-skill --package @porsche-design-system/components-react --location .claude/skills

# GitHub Copilot
npx pds-skill --package @porsche-design-system/components-react --location .github/skills
```

#### Create the symlink manually

On macOS or Linux, create the same project-local link from the repository root:

```bash
mkdir -p .agents/skills
ln -s "$(pwd)/node_modules/@porsche-design-system/components-react/skills/pds-knowledge-react" \
  .agents/skills/pds-knowledge-react
```

### 3. Verify the skill

Reload your AI coding agent or start a new agent session, then confirm that `pds-knowledge-{js|angular|react|vue}` is
available:

- **Claude Code:** Type `/` and look for the skill.
- **GitHub Copilot CLI:** Run `/skills reload`, then `/skills list`.
- **Codex:** Run `/skills` or type `$` and look for the skill.

## Install with an AI Agent

An AI coding agent can inspect the project, select the installed Porsche Design System package and create the symlink
with the bundled binary. Start the agent from the repository root and use this prompt:

```text
Set up the bundled Porsche Design System Knowledge Skill for this repository. Inspect the project dependencies to find
the installed @porsche-design-system/components-{js|angular|react|vue} package. Choose the skills directory for your
agent integration (.agents/skills for the Agent Skills standard and Codex, .claude/skills for Claude Code, or
.github/skills for GitHub Copilot). Run npx pds-skill with the installed package and selected location, then verify that
the generated skill symlink exists and points to the package's skill directory. Do not change project dependencies or
replace a non-symlink file or directory.
```

If the project contains multiple supported packages or the target agent integration is unclear, the agent should ask
which package and skills directory to use before making changes.

## How to Use the Skill

Use the Knowledge Skill whenever a task touches frontend UI/UX in a project where PDS is used.

A skill can be invoked in two ways:

- **Automatic invocation:** Your AI coding agent activates the skill when a task matches its description.
- **Manual invocation:** Invoke `pds-knowledge-{js|angular|react|vue}` using your agent's skill selection syntax to make
  sure it is used, for example `/pds-knowledge-react`.

### Example prompts

These examples use the React skill with slash-command syntax. Replace `react` with the framework used by your project.

Ask for version-specific guidance:

```text
/pds-knowledge-react Recommend the right PDS components for a responsive sign-in form. Explain the relevant properties,
slots and accessibility requirements for the version installed in this project.
```

Implement a feature:

```text
/pds-knowledge-react Build an accessible country selector that displays each country's flag in its option and groups the
countries by continent. Use the appropriate PDS components and follow the existing framework and codebase conventions.
```

Review existing code:

```text
/pds-knowledge-react Review this page for deprecated or incorrect PDS usage, accessibility issues and opportunities to
replace custom UI with PDS components. Apply the necessary fixes.
```

Update an implementation:

```text
/pds-knowledge-react Migrate this implementation to the APIs supported by the installed PDS version. Preserve its behavior
and accessibility, and verify the result.
```
