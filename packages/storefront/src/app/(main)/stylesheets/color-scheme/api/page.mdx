# Color Scheme

## CSS Classes

| CSS classes                                      | Usage                                                                                  | Description                                                                                                         |
| ------------------------------------------------ | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| <Code variant="nowrap">.scheme-normal</Code>     | `<html class="scheme-normal">…</html>` or `<div class="scheme-normal">…</div>`         | Sets `color-scheme: normal`. The element isn't rendered with any color scheme at all — the browser default applies. |
| <Code variant="nowrap">.scheme-light</Code>      | `<html class="scheme-light">…</html>` or `<div class="scheme-light">…</div>`           | Sets `color-scheme: light`. Indicates the element supports only the light color scheme.                             |
| <Code variant="nowrap">.scheme-dark</Code>       | `<html class="scheme-dark">…</html>` or `<div class="scheme-dark">…</div>`             | Sets `color-scheme: dark`. Indicates the element supports only the dark color scheme.                               |
| <Code variant="nowrap">.scheme-light-dark</Code> | `<html class="scheme-light-dark">…</html>` or `<div class="scheme-light-dark">…</div>` | Sets `color-scheme: light dark`. Indicates the element supports both light and dark, chosen by user preference.     |
| <Code variant="nowrap">.scheme-only-light</Code> | `<html class="scheme-only-light">…</html>` or `<div class="scheme-only-light">…</div>` | Sets `color-scheme: only light`. Forces the light color scheme and prevents the browser from overriding it.         |
| <Code variant="nowrap">.scheme-only-dark</Code>  | `<html class="scheme-only-dark">…</html>` or `<div class="scheme-only-dark">…</div>`   | Sets `color-scheme: only dark`. Forces the dark color scheme and prevents the browser from overriding it.           |
