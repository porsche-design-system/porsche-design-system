`p-select-option` only allows `#text` and `img` nodes unless the parent `p-select` provides a custom selection renderer
through the `selected` slot, which also enables custom option markup. This allows you to render different content in the
selected area versus the dropdown options, enabling more complex option layouts.

When using the `filter` option, the default behavior filters against all `textContent` within the options. For more
granular control over filtering, implement custom filtering logic as shown in the
[previous example](/components/select/examples#custom-asynchronous-filtering).
