Teasers lead to further content like an article, a campaign or a product page. An image teaser places media in the
`background` slot, a content teaser shows its content in the default slot. Both become clickable via the `anchor` slot
and repeat the link visually in the `bottom` slot.

- **Zoom:** Scale the slotted background media, e.g. via `group-has-[[slot=anchor]:hover,.primary-link:hover]:scale-105`
  with `group` on the Tile. The background is clipped to the border radius of the Tile.
- **Background color:** Override the `--p-tile-bg` CSS variable, e.g. via
  `has-[[slot=anchor]:hover,.primary-link:hover]:[--p-tile-bg:var(--color-contrast-lower)]`.

The visible link duplicates the anchor, so it is hidden from assistive technology and keyboard (`aria-hidden="true"` and
`tabindex="-1"`). It receives pointer events via `pointer-events-auto` to show its own hover state and is included in
the hover selector (here via the marker class `primary-link`), so the effect of the Tile stays active while the link is
hovered.
