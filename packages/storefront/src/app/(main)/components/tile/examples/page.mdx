# Tile <ComponentStatus tagName="p-tile"></ComponentStatus>

The examples are structured by use case. Clickable use cases with a visible link set `cover` on it, which stretches the
clickable area of the `p-link` over the Tile and renders the focus indicator around the Tile. Use cases without a
visible link use the `anchor` slot instead, which covers the whole Tile with a visually hidden link and makes all other
content click-through. Independent interactive elements are placed above a covering link via `relative z-2`, or opt in
via `pointer-events: auto` when the `anchor` slot is used. Use cases with multiple independent actions or none at all
use neither.

The Tile has no built-in hover effect, so each clickable use case shows how to tailor it to its content. The Tile
animates changes of `--p-tile-bg`, `--p-tile-media-scale` and `--p-tile-media-offset` and omits the movement of the
media if the user prefers reduced motion. Other effects are wrapped in `motion-safe:` to respect this preference. Hover
effects are a visual enhancement only, keyboard users get the focus indicator of the link.

## Slot-based Layouts

These use cases are built with the slots of the Tile: the content is placed in the `top`, `start`, default, `end` and
`bottom` slots, the `background` slot holds a mood image and properties like `aspect-ratio`, `compact`, `gradient` and
`bleed` adapt the Tile to its content. Custom styles are limited to the content itself, e.g. spacing or hover effects.

## Custom Layouts (Pattern Candidates)

These use cases bypass the layout of the Tile: they stretch the default slot to define their own grid, or remove the
padding, background and corner radius of the Tile, so it only provides the clickable area and its focus indicator. Since
most of the layout is custom code, they are candidates for a pattern rather than use cases of the Tile.

For comparison, each of these examples shows the Tile with the `anchor` slot, a counterpart built with Tailwind CSS only
and, for use cases with a visible link, the Tile with a covering `p-link`. The Tailwind CSS counterpart stretches a link
over the whole tile via `after:absolute after:inset-0 after:z-1`, which also renders the focus indicator around the
tile, and places independent interactive elements above it via `relative z-2`.
