# Tile <ComponentStatus tagName="p-tile"></ComponentStatus>

The examples are structured by use case. Clickable use cases with a visible link set `cover` on it, which stretches the
clickable area of the `p-link` over the Tile and renders the focus indicator around the Tile. Use cases without a
visible link use the `anchor` slot instead, which covers the whole Tile with a visually hidden link and makes all other
content click-through. Independent interactive elements are placed above a covering link via `relative z-2`, or opt in
via `pointer-events: auto` when the `anchor` slot is used. Use cases with multiple independent actions or none at all
use neither.

The Tile has no hover effect by default, so each clickable use case shows how to tailor it to its content.
`hover-effect` applies effects while the link of the Tile is hovered, so independent interactive elements don't trigger
them: `zoom` and `offset` zoom in on or move the media, `highlight` changes the background. They can be combined,
separated by a space. For other triggers or values, set `--p-tile-media-scale`, `--p-tile-media-offset` or `--p-tile-bg`
instead. The Tile animates these changes and omits the movement of the media if the user prefers reduced motion. Other
effects are wrapped in `motion-safe:` to respect this preference. Hover effects are a visual enhancement only, keyboard
users get the focus indicator of the link.
