# Tile <ComponentStatus tagName="p-tile"></ComponentStatus>

The examples are structured by use case. The Tile has no built-in hover effect, so each use case shows how to tailor it
to its content with a few custom styles. Since the slotted `anchor` covers the whole Tile and all other content is
click-through, hovering the anchor equals hovering the Tile, while independent interactive elements (which opt in via
`pointer-events: auto`) don't trigger it. Wrap transitions in `motion-safe:` to respect the user's preference for
reduced motion. Hover effects are a visual enhancement only, keyboard users get the focus indicator of the anchor.
