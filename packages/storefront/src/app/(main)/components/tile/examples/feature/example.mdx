A feature tile explains a single feature of a vehicle, e.g. within a model page of porsche.com. It is not interactive,
so it has no `anchor`. With `aspect-ratio="auto"` the Tile adapts its height to the content, and
`[--p-tile-gap-y:var(--spacing-fluid-md)]` increases the space between image and text.

The image is placed in the default slot. `bleed` lets the default slot reach the top and side edges of the Tile, since
only the `bottom` slot is occupied, and lets the image span its full width cover-fit. With `aspect-ratio="auto"`,
`aspect-video` defines the height of the image. The Tile clips the image to its corner radius.

Heading, text and footnote are wrapped in a single element in the `bottom` slot, which spans the full width via `grow`.
The footnote reference is marked up as `<sup>`, the footnote itself uses `size="xs"` and `color="contrast-medium"`.

The Tailwind CSS counterpart stacks image and text via `flex flex-col gap-fluid-md p-fluid-md`. Since there is no
stretched link, the tile itself clips the image to the radius via `overflow-clip`, and the image uses the padding as
negative margins (`-mt-fluid-md -mx-fluid-md`).
