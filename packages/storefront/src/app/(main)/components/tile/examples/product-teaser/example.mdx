A product teaser links to a product with a branded background color, e.g. within a product category of porsche.com.
`[--p-tile-bg:#341f2e]` overrides the background color of the Tile, and the `scheme-dark` class renders light content
independent of the color scheme of the page. Make sure the custom color provides sufficient contrast for the content.

The image is placed in the `start` slot, whose column takes up to half of the Tile. It fills the height of the slot via
`grow basis-0 min-h-0` without increasing the height of the Tile, and `object-contain` centers it within the slot.
Heading and text are wrapped in a single element in the default slot, which centers it vertically, while
`self-stretch text-start` aligns the text to the start. `hyphens="auto"` lets the heading break when the Tile gets
narrow. The arrow link is placed in the `end` slot, `mb-auto` aligns it to the top.

The `anchor` slot makes the whole Tile clickable and provides the accessible link to the product. The visible arrow link
duplicates it, so it is hidden from assistive technology and keyboard (`aria-hidden="true"` on the link and
`tabindex="-1"` on its slotted anchor) but opts in via `pointer-events-auto` to show its own hover state.

On hover of the `anchor` or the duplicated link, the image zooms in via
`group-has-[[slot=anchor]:hover,p-link[aria-hidden]:hover]:scale-105`. The `motion-safe:` variant respects the reduced
motion preference of the user.

The Tailwind CSS counterpart splits the tile into an outer element, which is the positioning context of the stretched
link and carries the radius, and an inner element, which clips the image to the radius via
`overflow-clip rounded-[inherit]`. It mirrors the `start`, default and `end` slots via
`grid-cols-[fit-content(50%)_minmax(0,1fr)_fit-content(50%)]`, while `grid-rows-[minmax(0,1fr)]` keeps the image from
increasing the height of the tile. The image is wrapped in a flex column like in the `start` slot.
