A model selection lets users pick a model range as entry point, e.g. to browse the available vehicles of the Porsche
Finder. The Tile shows the model signature, the model name and a side view of the vehicle in the default slot, while the
`anchor` slot makes the whole Tile clickable. With `aspect-ratio="auto"` the Tile adapts its height to the content, and
`[--p-tile-gap-y:0]` removes the gap between signature and name, so only the image is spaced via `mt-static-sm`.

On hover of the `anchor`, the vehicle zooms in via `hover-effect="zoom"`. Since all content is click-through, hovering
anywhere on the Tile hovers the anchor. The Tile animates the zoom and omits it if the user prefers reduced motion.
