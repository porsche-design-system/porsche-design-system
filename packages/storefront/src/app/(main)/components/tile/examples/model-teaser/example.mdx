A model teaser introduces a model range with its starting price and links to discover and configure it, e.g. on the
homepage of porsche.com. All content is placed in the default slot, which stacks and centers it.

The model signature is placed behind the side view of the vehicle by stacking both in the same grid cell via
`[grid-area:1/1]`, while `mt-[6%]` lets the vehicle overlap the lower part of the signature. The mask of the signature
paints it above non-positioned content, so `z-1` places the vehicle in front of it. `grid-cols-1` prevents the natural
width of the image from widening the grid. `[--p-model-signature-width:75%]` scales the signature and
`[--p-model-signature-color:var(--color-canvas)]` renders it in the canvas color, which stands out subtly from the
surface of the Tile in both color schemes. `safe-zone="false"` removes the spacing around it.

`cover` on the "Discover 911" link stretches its clickable area over the Tile, so the whole Tile links to the model, and
renders the focus indicator around the Tile. The "Configure" link is an independent action, so it is placed above the
covering link via `relative z-2` to stay clickable. Its accessible name is extended via `aria-label` to identify the
model, while it still contains the visible label.

Since hovering the Tile hovers the "Discover 911" link, the link shows its own hover state, and the vehicle zooms in via
`motion-safe:group-has-[a:hover]:scale-105`. The vehicle is nested within the default slot, so it is zoomed via its own
classes instead of `--p-tile-media-scale`. `group-has-[a:hover]` only matches the slotted anchor of the covering link,
since the "Configure" link renders its anchor in its shadow DOM, so hovering "Configure" doesn't zoom the vehicle. The
`motion-safe:` variant omits the zoom and its transition if the user prefers reduced motion.
