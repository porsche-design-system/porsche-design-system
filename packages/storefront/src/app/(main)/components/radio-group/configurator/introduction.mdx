The `p-radio-group` component is a versatile custom form element that enables the selection of a single option.

<Notification heading="Attention" heading-tag="h2" state="warning">
  The <code>blur</code> event is emitted whenever the focused <code>p-radio-group-option</code> changes — not only when
  the entire <code>p-radio-group</code> loses focus. This means that switching between options within the same group
  will also trigger a <code>blur</code> event for the previously focused option.
</Notification>

Options are slotted using the `p-radio-group-option` component. Each option needs an assigned `string` or `number`
value. The `p-radio-group` value matches an option strictly by type and value, so a number does not match the equivalent
string. Use `undefined` or `null` for no preselection. Initial selection states can only be achieved using the `value`
property on the `p-radio-group` component. If an option should be visible but not selectable, it can be disabled using
the `disabled` attribute.

A `label` is a caption which informs the user what information a particular form field is asking for. The
`p-radio-group` component can be used with or without a label, but it's recommended to keep the label visible for better
accessibility whenever possible. When used without a label, it's best practice to provide a descriptive label text for
screen readers.
