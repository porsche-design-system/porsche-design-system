A search field with a result list composed with [`p-popover`](/components/popover/configurator) is provided as different patterns:

### The combobox pattern

The [dealer results](/patterns/forms/resources#dealer-results) pattern shows this as an exampke integration. Typing filters the choices,
the arrow keys move a highlight, and Enter or the search button writes the highlighted choice into the field.

### The links pattern

The [dealer links](/patterns/forms/resources#dealer-links) pattern uses the same field when a match is a page of its
own. The results stay real links inside a dialog, the arrow keys move a highlight, and Enter or a click opens the
highlighted page.
