The `p-input-url` component provides a user-friendly, accessible interface for entering valid website URLs. It leverages
native HTML5 URL validation and ensures appropriate keyboard behavior on mobile devices. It includes `start` and `end`
slots to flexibly incorporate icons, buttons, or other elements within the input field.

A `label` tells the user what information a form field is asking for. The `p-input-url` component can be used with or
without a label, but it is recommended to keep the label visible whenever possible for better accessibility. When used
without a label, a descriptive label text for screen readers is required.

A `placeholder` is optional, but recommended when example content or hints should be shown to give the user visual cues
for completing the form.

<FrameworkNotification showForFrameworks={['react']} heading="Input Event Handling">
  React's `onChange` behaves like the native `onInput` (fires on every keystroke). However, our web components follow
  standard browser behavior, where `onChange` only fires when the input loses focus. To get real-time updates on each
  keystroke, use `onInput` instead.
</FrameworkNotification>
