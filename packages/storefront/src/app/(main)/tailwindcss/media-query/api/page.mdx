## Variables

| Tailwind CSS variable                                    | Tailwind CSS class                                                              | Description                                                   |
| -------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| <Code variant="nowrap">--breakpoint-xs</Code>     | <Code variant="nowrap">{'.xs:\*'}</Code>, <Code variant="nowrap">{'.max-xs:\*'}</Code>                  | Applies a media query with the `xs` (**480px**) breakpoint.   |
| <Code variant="nowrap">--breakpoint-sm</Code>     | <Code variant="nowrap">{'.sm:\*'}</Code>, <Code variant="nowrap">{'.max-sm:\*'}</Code>, <Code variant="nowrap">{'.xs:max-sm:\*'}</Code>  | Applies a media query with the `sm` (**760px**) breakpoint.   |
| <Code variant="nowrap">--breakpoint-md</Code>     | <Code variant="nowrap">{'.md:\*'}</Code>, <Code variant="nowrap">{'.max-md:\*'}</Code>, <Code variant="nowrap">{'.md:max-lg:\*'}</Code>  | Applies a media query with the `md` (**1000px**) breakpoint.  |
| <Code variant="nowrap">--breakpoint-lg</Code>     | <Code variant="nowrap">{'.lg:\*'}</Code>, <Code variant="nowrap">{'.max-lg:\*'}</Code>, <Code variant="nowrap">{'.lg:max-xl:\*'}</Code>  | Applies a media query with the `lg` (**1300px**) breakpoint.  |
| <Code variant="nowrap">--breakpoint-xl</Code>     | <Code variant="nowrap">{'.xl:\*'}</Code>, <Code variant="nowrap">{'.max-xl:\*'}</Code>, <Code variant="nowrap">{'.xl:max-2xl:\*'}</Code> | Applies a media query with the `xl` (**1760px**) breakpoint.  |
| <Code variant="nowrap">--breakpoint-2xl</Code>    | <Code variant="nowrap">{'.2xl:\*'}</Code>, <Code variant="nowrap">{'.max-2xl:\*'}</Code>                | Applies a media query with the `2xl` (**1920px**) breakpoint. |
