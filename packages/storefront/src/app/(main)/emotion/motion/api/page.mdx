### Duration

| JS                                              | Description                                                         | Value                                            |
| ----------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------ |
| <Code variant="nowrap">durationSm</Code> | Holds a **short** `transition-duration` / `animation-duration`.     | <Code variant="value">{durationSm}</Code> |
| <Code variant="nowrap">durationMd</Code> | Holds a **moderate** `transition-duration` / `animation-duration`.  | <Code variant="value">{durationMd}</Code> |
| <Code variant="nowrap">durationLg</Code> | Holds a **long** `transition-duration` / `animation-duration`.      | <Code variant="value">{durationLg}</Code> |
