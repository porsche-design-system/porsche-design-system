# Border

Defines the rounding of interactive controls, containers, and pill shapes. The visual language is primarily shaped by
**radiusXl** (`12px`) for controls and **radius3Xl** (`24px`) for tiles — establishing a consistent, modern appearance
across all touchpoints.
