# Introduction

<TableOfContents headings={['Setup']} />

Design tokens are the foundational building blocks of the Porsche Design System. They are named entities that represent
visual design attributes — such as colors, spacing, and typography — provided as raw data so they can be used with any
styling tool or framework.

We offer ready-to-use integrations for [Tailwind CSS](/tailwindcss/introduction), [SCSS](/scss/introduction),
[Emotion](/emotion/introduction), and [Vanilla Extract](/vanilla-extract/introduction), but these all build on top of
the same underlying tokens. This means you can also use the tokens directly to create your own custom styling solution
if needed.

## Setup

All tokens are available as plain JavaScript objects and can be imported using the following path:

```js
/* Replace {js|angular|react|vue} with your framework, e.g. components-react */
import { colorPrimary } from '@porsche-design-system/components-{js|angular|react|vue}/tokens';
```
