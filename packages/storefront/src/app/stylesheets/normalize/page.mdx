# Normalize

<TableOfContents headings={['Setup']} />

The Porsche Design System provides recommended **normalize styles** that include CSS reset styles and base typography
definitions.

## Setup

When you import the main package CSS file, the normalize styles are already included:

```css
/* Replace {js|angular|react|vue} with your framework, e.g. components-react */
@import '@porsche-design-system/components-{js|angular|react|vue}';
```

If you only need the normalize styles without any other styles, you can import them separately:

```css
@import '@porsche-design-system/components-{js|angular|react|vue}/normalize.css';
```
