## Variables

| CSS variable                                               | Tailwind CSS class                           | Description                                         |
| ---------------------------------------------------------- | -------------------------------------------- | --------------------------------------------------- |
| <Code variant="nowrap">--transition-duration-sm</Code> | <Code variant="nowrap">.duration-sm</Code>     | Applies a **short** `transition-duration`.          |
| <Code variant="nowrap">--transition-duration-md</Code> | <Code variant="nowrap">.duration-md</Code>     | Applies a **moderate** `transition-duration`.       |
| <Code variant="nowrap">--transition-duration-lg</Code> | <Code variant="nowrap">.duration-lg</Code>     | Applies a **long** `transition-duration`.           |
| <Code variant="nowrap">--transition-duration-xl</Code> | <Code variant="nowrap">.duration-xl</Code>     | Applies a **very long** `transition-duration`.      |
| <Code variant="nowrap">--ease-in-out</Code>            | <Code variant="nowrap">.ease-in-out</Code>     | Applies an **in-out** `transition-timing-function`. |
| <Code variant="nowrap">--ease-in</Code>                | <Code variant="nowrap">.ease-in</Code>         | Applies an **in** `transition-timing-function`.     |
| <Code variant="nowrap">--ease-out</Code>               | <Code variant="nowrap">.ease-out</Code>        | Applies an **out** `transition-timing-function`.    |
