# AI Tag <ComponentStatus tagName="p-ai-tag"></ComponentStatus>

## Accessibility support

The `ai-tag` component uses an `<abbr>` element to provide a tooltip with the full text when the content is truncated.
This allows screen readers to access the full content of the tag, even when it is visually truncated.
