The `size` property offers a set of predefined sizes that cover most use cases. To align the flag with surrounding
typography, set `size` to `inherit`. The flag's dimensions are then derived from the font-size of a parent element
(e.g. a `p-text`). The internal calculation is based on the `ex`-unit relative to the inherited font-size and the
global line-height, ensuring the flag stays visually consistent with typographic-scale-based components.
