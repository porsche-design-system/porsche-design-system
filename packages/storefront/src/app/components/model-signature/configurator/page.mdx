# Model Signature <ComponentStatus tagName="p-model-signature"></ComponentStatus>

The `p-model-signature` component is purely visual and renders the different signatures of Porsche car models. It can be
used to overlay background images or enhance cards and teasers to be more dynamic and recognizable.

<Notification heading="Sizing" heading-tag="h2" state="info">
  To preserve backwards compatibility, the `p-model-signature` is bound by its `width` — the `height` follows the
  signature's intrinsic aspect ratio automatically.

Setting `--p-model-signature-height` alone will not increase the rendered size, because the width fallback still
applies. If you need to constrain by height, set `--p-model-signature-width: auto` together with
`--p-model-signature-height`.

</Notification>
