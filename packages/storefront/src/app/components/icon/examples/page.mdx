## Overview

For more information and a complete overview of all available Porsche icons, head over to Porsche Icons
([Porsche Icons](https://icons.porsche.com)). To reference an icon just use the `name` property with a predefined icon
id.

<ComponentStory story={iconStoryOverview} />

## Size

There are predefined sizes for the component available which should cover most use cases. If a specific size is needed,
the `size` property can be set to `inherit` to derive the icon's dimensions from the font-size of a parent element (e.g.
a `p-text`). The calculation is based on the `ex`-unit relative to the inherited font-size and the global line-height,
ensuring the icon stays visually consistent with surrounding typographic-scale-based components.

<ComponentStory story={iconStorySize} />

Alternatively, the size can be controlled via the custom CSS variable `--p-icon-size`, which accepts any valid CSS
length value. This approach is particularly useful when the icon is placed independently of typographic-scale-based
components and a precise, fixed size is required.

<ComponentStory story={iconStorySizeCSSVar} />

The `size` property supports `BreakpointCustomizable` values, allowing you to define different sizes for each major
breakpoint (`xs`, `s`, `m`, `l`, `xl`). This makes it easy to adapt the icon's appearance responsively without
additional CSS.

<ComponentStory story={iconStoryResponsiveSize} />

## Color

The `color` property can be set to `inherit` to derive the icon's color from the `currentcolor` of a parent element
(e.g. a `p-text`). This ensures the icon matches the surrounding text color automatically.

<ComponentStory story={iconStoryColor} />

Alternatively, the color can be controlled via the custom CSS variable `--p-icon-color`, which accepts any valid CSS
color value. This allows full control over the icon's color independently.

<ComponentStory story={iconStoryColorCSSVar} />

## Custom icon

The whole Porsche icon set is hosted on the Porsche Design System CDN. If there is need to show a custom icon which
doesn't exist yet, you can define a custom path (absolute or relative) to your SVG icon in the `source` property. Be
sure that the custom icon serves the specific needs like size and viewbox which are described in the
[usage documentation](/components/icon/usage/).
