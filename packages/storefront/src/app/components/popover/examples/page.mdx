## Slotted button

The `p-popover` component can also be used with a **slotted button** via the `button` slot, allowing you to provide a
custom button element.

<ComponentStory story={popoverSlottedButtonStory} />

## Custom styling

The maximum width of the popover content can be customized using the `--p-max-content-width` CSS variable. By default,
the content width is limited to `min(calc(100dvw - safe zones), 48ch)`. Override this value when the popover contains
wider content such as tables or lists that benefit from additional horizontal space.
