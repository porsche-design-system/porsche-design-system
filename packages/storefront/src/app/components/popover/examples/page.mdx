## Custom styling

The maximum width of the popover content can be customized using the `--p-popover-max-w` CSS variable. By default, the
content width is limited to `min(calc(100dvw - safe zones), 48ch)`. Override this value when the popover contains wider
content such as tables or lists that benefit from additional horizontal space.
