## JS Functions

| JS Function                                                                                                            | Description                                                       |
| ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| <Code variant="nowrap">getMediaQueryMin('base'\|'xs'\|'s'\|'m'\|'l'\|'xl'\|'xxl')</Code>                               | Applies a **min** media query with the specified breakpoint.      |
| <Code variant="nowrap">getMediaQueryMax('xs'\|'s'\|'m'\|'l'\|'xl'\|'xxl')</Code>                                       | Applies a **max** media query with the specified breakpoint.      |
