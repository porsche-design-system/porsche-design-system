## SCSS Mixins

| SCSS Mixins                                                  | Description                                                                                                                             |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| <code className="whitespace-nowrap">@mixin pds-grid()</code> | Applies the **Porsche Grid** layout system (must be applied once at the top level, span the full viewport width, and cannot be nested). |
