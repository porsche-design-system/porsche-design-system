## SCSS Mixins

| SCSS Mixins                                     | Description                                                                                                                             |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| <Code variant="nowrap">@mixin pds-grid()</Code> | Applies the **Porsche Grid** layout system (must be applied once at the top level, span the full viewport width, and cannot be nested). |
