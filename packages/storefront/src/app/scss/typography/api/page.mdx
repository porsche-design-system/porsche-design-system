## SCSS Mixins

### Heading

| SCSS Mixin                                             | Description                                                                                                           |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| <Code variant="nowrap">@mixin prose-heading-5xl</Code> | Applies the **5x-large** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags. |
| <Code variant="nowrap">@mixin prose-heading-4xl</Code> | Applies the **4x-large** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags. |
| <Code variant="nowrap">@mixin prose-heading-3xl</Code> | Applies the **3x-large** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags. |
| <Code variant="nowrap">@mixin prose-heading-2xl</Code> | Applies the **2x-large** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags. |
| <Code variant="nowrap">@mixin prose-heading-xl</Code>  | Applies the **x-large** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags.  |
| <Code variant="nowrap">@mixin prose-heading-lg</Code>  | Applies the **large** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags.    |
| <Code variant="nowrap">@mixin prose-heading-md</Code>  | Applies the **medium** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags.   |
| <Code variant="nowrap">@mixin prose-heading-sm</Code>  | Applies the **small** heading typography variant primarily to `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>` tags.    |
