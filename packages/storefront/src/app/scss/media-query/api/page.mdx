## SCSS Mixins

| SCSS Mixins                                                                                                                                     | Description                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| <code className="whitespace-nowrap">@mixin media-query-min('xs'\|'sm'\|'md'\|'lg'\|'xl'\|'2xl')</code>                                          | Applies a **min** media query with the specified breakpoint.      |
| <code className="whitespace-nowrap">@mixin media-query-max('xs'\|'sm'\|'md'\|'lg'\|'xl'\|'2xl')</code>                                          | Applies a **max** media query with the specified breakpoint.      |
