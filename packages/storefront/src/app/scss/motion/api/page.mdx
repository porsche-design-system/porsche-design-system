## SCSS Variables

### Duration

| SCSS variable                                           | Description                                                         | Value                                             |
| ------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------- |
| <code className="whitespace-nowrap">$duration-sm</code> | Holds a **short** `transition-duration` / `animation-duration`.     | <code className="select-none">{durationSm}</code> |
| <code className="whitespace-nowrap">$duration-md</code> | Holds a **moderate** `transition-duration` / `animation-duration`.  | <code className="select-none">{durationMd}</code> |
| <code className="whitespace-nowrap">$duration-lg</code> | Holds a **long** `transition-duration` / `animation-duration`.      | <code className="select-none">{durationLg}</code> |
| <code className="whitespace-nowrap">$duration-xl</code> | Holds a **very long** `transition-duration` / `animation-duration`. | <code className="select-none">{durationXl}</code> |

### Ease

| SCSS variable                                           | Description                                       | Value                                            |
| ------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------ |
| <code className="whitespace-nowrap">$ease-in-out</code> | Holds an **in-out** `transition-timing-function`. | <code className="select-none">{easeInOut}</code> |
| <code className="whitespace-nowrap">$ease-in</code>     | Holds an **in** `transition-timing-function`.     | <code className="select-none">{easeIn}</code>    |
| <code className="whitespace-nowrap">$ease-out</code>    | Holds an **out** `transition-timing-function`.    | <code className="select-none">{easeOut}</code>   |
