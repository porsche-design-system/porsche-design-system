## Usage

Use the AI Tag to indicate AI-generated or AI-assisted content.

The following segment provides instructions for designers and developers regarding the appropriate utilization of this
component in various situations.

### Do:

- Use to label content that is AI-generated or AI-assisted.
- Use to indicate the type of AI processing applied (e.g., text, image, code, video).
- Use the `locale` prop to display the correct text for your target language.
- Use the `icon` prop to select an appropriate AI icon for the context.
- Use the `textVariant` prop to switch between the abbreviation (default) and the full spelled-out text.

### Don't:

- Don't use for non-AI related labeling — use `p-tag` instead.
- Don't use for interactive or clickable labels.
