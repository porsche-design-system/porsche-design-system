There are predefined sizes for the component available which should cover most use cases. If a specific size is needed,
the `size` property can be set to `inherit` to derive the spinner's dimensions from the font-size of a parent element
(e.g. a `p-text`). The internal calculation is based on the `ex`-unit relative to the inherited font-size and the global
line-height, ensuring the spinner stays visually consistent with surrounding typographic-scale-based components.
